What to set on the firewall (values already filled in) {% if fw.kind == 'pfsense' %}
  1. pfSense: Status → System Logs → Settings. Tick Send log messages to remote syslog server. Remote log servers: {{ ip }}:{{ port }}. Remote Syslog Contents: tick Firewall Events. Log message format: BSD (RFC 3164). Save.
    OPNsense: System → Settings → Logging / targets → +. Transport UDP(4), Applications filter (filterlog), Hostname {{ ip }}, Port {{ port }}, RFC5424 off. Save and Apply.
  2. On the rules that block traffic from this network, tick Log packets that are handled by this rule. In pfSense also tick Log packets matched from the default block rules (Status → System Logs → Settings). Apply.
  3. Windows may ask whether Python may receive network traffic: choose Allow. The status above turns green with the first log.
{% elif fw.kind == 'iptables' %}
  1. On the Linux firewall, log what is dropped (run as root, before the final drop):
    iptables -A FORWARD -j LOG --log-prefix "SEGCHECK-DROP "
  2. Send kernel logs to this PC: create /etc/rsyslog.d/90-segcheck.conf with the line kern.* @{{ ip }}:{{ port }}, then systemctl restart rsyslog.
  3. Windows may ask whether Python may receive network traffic: choose Allow. The status above turns green with the first log.
